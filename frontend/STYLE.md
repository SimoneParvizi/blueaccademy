# blueaccademy Design System

## Color Palette

### Primary Color Palette
- **Paper Background (Light Mode)**: `#F5F1E8` - Warm cream/beige base
- **Dark Background (Dark Mode)**: `#1A1A1A` - Deep charcoal
- **Primary Accent Blue (Light)**: `#2563EB` - Rich cobalt blue
- **Primary Accent Blue (Dark)**: `#3B82F6` - Bright sky blue
- **Divider Color (Light)**: `#E5E3DB` - Subtle warm gray
- **Divider Color (Dark)**: `#333333` - Dark gray divider

### Text & Contrast
- **Text (Light Mode)**: `#333333` - Dark charcoal
- **Text (Dark Mode)**: `#E0E0E0` - Light gray
- **Muted Text (Light)**: `#888888` - Medium gray
- **Muted Text (Dark)**: `#A0A0A0` - Light gray
- **Secondary Elements (Light)**: `#666666` - Dark gray
- **Secondary Elements (Dark)**: `#CCCCCC` - Light gray

### UI Component Colors
- **Code Editor Background**: `#1E1E1E` - Dark gray (consistent in both modes)
- **Code Editor Tabs**: `#252526` - Slightly lighter dark
- **Button Background (Light)**: `#FFFFFF` - Pure white
- **Button Background (Dark)**: `#252525` - Dark panel
- **Hover State (Light)**: `#F5F1E8` - Paper color
- **Hover State (Dark)**: `#1A1A1A` - Dark paper

### Code Syntax Colors (VS Code Dark Theme)
- **Keywords**: `#569CD6` - Steel blue
- **Strings**: `#CE9178` - Warm orange-brown
- **Numbers**: `#B5CEA8` - Sage green (complement to blue)
- **Base Text**: `#D4D4D4` - Light gray

## Typography Stack
- **Headers/Display**: Playfair Display (serif, elegant)
- **Brand Name**: Space Grotesk (sans-serif, technical)
- **Body Text**: Inter (sans-serif, clean)
- **Code/Technical**: JetBrains Mono (monospace)

## Theme Toggle
- **Light Mode**: Paper background + Dark text + Cobalt blue accents
- **Dark Mode**: Charcoal background + Light text + Sky blue accents
- **Smooth Transition**: 0.3s ease on all color changes

## Design Principles
- Elegant portfolio aesthetic with sophisticated typography
- Three-column layout: instructions | file tree | code editor
- Seamless light/dark mode with smooth color transitions
- Premium academy branding with cobalt blue as primary accent
- Clean, minimal design with 1px dividers (no shadows)
- Professional, polished, and refined visual identity
